# Музыка — Android-приложение

Минималистичный тёмный плеер. Импорт аудио с устройства (MP3, M4A, FLAC, OGG, WAV, OPUS), обложки и теги
читаются из файлов, библиотека сохраняется внутри приложения. Интернет не используется.

## Как получить APK

### Вариант 1 — без установки чего-либо (GitHub)
1. Создайте пустой репозиторий на github.com.
2. Загрузите в него всё содержимое этой папки (вместе со скрытой папкой `.github`).
3. Откройте вкладку **Actions** → **Build APK** → **Run workflow**.
4. Через 3–5 минут скачайте артефакт **Muzyka-apk** — внутри `app-debug.apk`.
5. Перенесите файл на телефон, откройте его и разрешите установку из этого источника.

### Вариант 2 — Android Studio
1. **File → Open** → выберите эту папку, дождитесь синхронизации Gradle.
2. **Build → Build APK(s)** → `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 3 — командная строка
Нужны JDK 17, Android SDK (platform 34) и Gradle 8.7:

    gradle assembleDebug

## Структура
- `app/src/main/assets/index.html` — весь интерфейс и логика плеера
- `app/src/main/java/com/muzyka/player/MainActivity.java` — WebView и системный выбор файлов
- `.github/workflows/build-apk.yml` — автосборка APK

## Ограничения
- Воспроизведение идёт через встроенный WebView: поддерживаются форматы, которые он умеет декодировать на вашем устройстве.
- Музыка продолжает играть при сворачивании приложения, но без управления из шторки уведомлений
  (для этого нужен foreground-сервис — можно добавить отдельно).
- Файлы копируются в хранилище приложения; при удалении приложения библиотека удаляется.
